# protobuf-dynamic

Library to create Protocol Buffers schemas programmatically at runtime, with no `protoc` compiler required. It is a fork of [os72/protobuf-dynamic](https://github.com/os72/protobuf-dynamic), refactored to proto3 and used by the ThingsBoard platform.

Published as `org.thingsboard:protobuf-dynamic`.
